BEST PRACTICES PROVIDED
═══════════════════════════════════════════════════════════════════════════════

1. INPUT VALIDATION
   - Server-side validation required
   - Whitelist approach preferred
   - Type checking for parameters
   - Length limits on inputs

2. DATABASE SECURITY
   - Parameterized queries (prepared statements)
   - Principle of least privilege
   - No database error exposure
   - Encrypted sensitive data

3. AUTHENTICATION
   - Strong password hashing (bcrypt, scrypt, pbkdf2)
   - Secure session management
   - Account lockout mechanisms
   - Rate limiting

4. SECRETS MANAGEMENT
   - Never hardcode secrets
   - Environment variable configuration
   - Regular secret rotation
   - Secret management systems (Vault, AWS Secrets)

5. ERROR HANDLING
   - Generic user-facing errors
   - Detailed internal logging
   - Exception handling
   - No sensitive info in errors

6. CONFIGURATION
   - Environment-specific settings
   - Debug mode disabled in production
   - Separate dev/staging/prod configs

7. DEPENDENCIES
   - Keep libraries updated
   - Regular security audits
   - Vulnerability scanning
   - Review security advisories

8. OUTPUT ENCODING
   - HTML escaping in HTML context
   - URL encoding in URLs
   - JSON encoding for APIs
